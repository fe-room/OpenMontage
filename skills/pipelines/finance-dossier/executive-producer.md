# Finance Dossier — Executive Producer

Orchestrate `research -> proposal -> script -> scene_plan -> assets -> edit -> compose -> cover -> publish` from `pipeline_defs/finance-dossier.yaml`. Before each stage, read its director, `creative/finance-editorial-direction`, `creative/finance-storytelling`, the active conditional finance editorial skill, `meta/reviewer`, and `meta/checkpoint-protocol`.

## Binding run rules

1. Set canonical `content_category: finance` at research/proposal intake so the conditional finance policy resolves at every declared stage.
2. Use existing canonical artifacts; Finance Editorial Direction lives in artifact metadata and component props remain additive fields, not a parallel artifact system.
3. At proposal, recommend by content fit before checking availability. Present Remotion and HyperFrames, all three motion-coverage strategies, and templated versus atelier authoring. Await explicit approval.
4. Keep `decision_log` append-only and carry `render_runtime`, `composition_mode`, voice, music, and motion commitment forward unchanged unless the user approves and a revised decision is appended.
5. Stop at every manifest gate. The assets filmstrip and real cover each require separate human approval.
6. The ending frame must contain exactly `本视频仅作知识分享，不构成任何投资建议。市场有风险，投资需谨慎。` as native readable text. Normally carry it as footer/overlay metadata on the final meaningful editorial scene; use a standalone card only when explicitly requested or externally required.

## Cross-stage gates

- Research: route the editorial task before broad research; Tier 1 first, mode-aware source priorities, source hierarchy recorded, claims classified.
- Proposal: confirm or revise Editorial Direction from evidence; evidence-backed concepts, honest capabilities/cost, explicit runtime and authoring mode.
- Script: consume Editorial Direction as a prior rather than a template; preserve uncertainty and omit irrelevant grammar beats.
- Scene plan: mode-aware DOCUMENT/DATA/MECHANISM/DECISION jobs, source anchors, existing V1.2 canvas/density treatments, validator warnings reviewed.
- Assets/edit: provenance survives into cuts; no fabricated values or meaningless finance imagery.
- Compose: composition validator, runtime checks, ffprobe, audio verification, representative frames, readable sources, exact ending.
- Publish: local evidence/source notes accompany the video; packaging never turns scenarios into promises.

Send work backward when downstream evidence contradicts an earlier claim. Do not patch over evidence conflicts in the edit.
