# 小散经济学 03 — 纸张质感方向 v2

> 本文件在授权场景之前写下，用于承诺**本期专属**的视觉语言。
> 第 02 期已建立的材质参数保留，但**标志装置重新设计**，不做模板复用。

## 基纸

- 中性象牙白 `#F4F1E8`。避免整屏泛黄，也避免大面积纯黄。
- 材质层：低频明暗起伏、静态细颗粒（固定 seed，**不逐帧随机**）、稀疏纸纤维、边缘压暗。
- 为什么固定 seed：逐帧随机在 H.264 压缩后会闪烁与爬动，破坏"纸"的实物质感。

## 空间层

- 纸片之间使用 1px 暗边 + 克制投影 + 轻微旋转（±0.4°~0.9°），形成真实厚度。
- 纸片不悬空：每张纸必须有可解释的层级关系（压在上面的、被压住的）。

## 印刷层（四色，不引入第五种强调色）

| 用途 | 颜色 | 说明 |
|---|---|---|
| 正文 / 定义 | 石墨黑 | 主体文字 |
| 反转 / 纠偏 | 朱红 | 只用于三次反转与"成本≠错误"纠偏 |
| 关系 / 箭头 | 深青 | 只用于因果与箭头，不用于强调 |
| 承载 | 象牙白 | 纸底 |

- 允许极轻微的套印偏差（≤1px）以保留印刷感。
- 朱红是稀缺资源：**全片朱红出现次数应当可数**，一旦泛滥就失去强调作用。

## 本期标志装置：四张选项纸卡

本期**唯一**的标志装置。承担"选择集合 → 选中 → 放弃 → 高亮"的全部机制表达。

1. **建立**：四张等权纸卡（A 在家休息 / B 拍一期视频 / C 接一个兼职 / D 去健身）并排出现，上方压一行"周六下午：4 小时"。
2. **约束**：一条朱红横线划过四张卡——"这 4 个小时，你只能真正使用一次"。
3. **选中**：A 卡被抬起、加厚；B/C/D 变暗（不是消失，保留可读的轮廓）。
4. **高亮**：被放弃的那一张（C）重新点亮，其余保持变暗 —— 这一步就是"最佳被放弃方案"。
5. **澄清**：第二次反转时，B/C/D 被逐个熄灭，并伴随一道被划掉的加号算式，视觉上否定"相加"。
6. **纠偏**：第三次反转时用朱红批注覆盖，而非新增卡片。

**禁止**：把四张卡做成四个独立的圆角矩形按钮（那是 UI，不是纸）。

## 动态规则

- 节奏服从规划第 18 节：**快 → 慢 → 停 → 快 → 慢 → 收**。
  - 开场快：躺一天 / 0元 / 成本=0？三屏大字快速切换。
  - 中段慢：4 小时场景，让选择集合被真正读完。
  - 揭晓停：出现"机会成本"时，知识卡单独停留一屏。
  - 第二次反转快：多选项熄灭 + 算式被划掉。
  - 第三次反转慢：纠偏需要被读完，不能抢。
  - 结尾收：只留一个追问。
- **不铺设整段口播字幕**。字幕分层：短句大字 → 关键词强调 → 极少数完整句。让视觉承担一部分理解任务。

## 禁止项

- 大面积纯黄、咖啡渍式做旧、全局强噪点。
- 每个信息组都套卡片。
- 过重阴影。
- 满屏滚动字幕。
- 金币飘落、K 线、握手、机房等泛金融空镜（已判定为 decorative_only）。

## 竖屏约束

- 1080×1920 / 30fps。
- 字幕安全区：距底 **520px**、距侧各 **96px**，为平台标题、账号行与互动栏让位。
- 关键定义文字与数字必须落在安全区内。
